# Macro Recorder

## What is it?
A simple Python tool that records keyboard inputs and replays them in a loop.

## Why am I building this?
Quick macro tool for automating repetitive key sequences — press a hotkey to record, press again to replay on loop.

## Steps
- [ ] Step 1: Build the recorder script (record + replay + hotkeys)

## Today's Goal
Get a working macro recorder we can run from Python.

## Controls
- F9: Start/stop recording
- F10: Start/stop playback (loops continuously)
- ESC: Quit
